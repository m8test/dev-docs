背景

默认情况下不显示背景图片, 如果需要显示背景图片可以通过以下步骤实现

显示背景

在app主页点击设置

点击其他

点击显示背景右边的开关即可显示/隐藏背景

配置背景图片

在app主页点击存储

选择内部

在根目录下找到 config 目录, 如果没有的话就创建

进入 config 目录, 找到 Background 目录, 如果没有就创建

进入 Background 目录, 可以创建 light.json 和 dark.json 两个文件, 一个用于在亮色模式下显示的背景配置, 一个用于暗色模式下显色的背景配置, 如果仅仅配置了 light.json 或者 dark.json 也是可以的, 如果是这样的话另外一个没有配置的模式则使用默认值, 这里演示仅仅暗色模式下的背景配置

这里 dark.json 文件内容为

{ "default": "https://bkimg.cdn.bcebos.com/pic/9e3df8dcd100baa1cd11c779b144ae12c8fcc2ce80ee?x-bce-process=image/format,f_auto/watermark,image_d2F0ZXIvYmFpa2UyNzI,g_7,xp_5,yp_5,P_20/resize,m_lfit,limit_1,h_1080", "home": "https://bkimg.cdn.bcebos.com/pic/b64543a98226cffc1e17a44900585d90f603728dbc8d?x-bce-process=image/format,f_auto/watermark,image_d2F0ZXIvYmFpa2UyNzI,g_7,xp_5,yp_5,P_20/resize,m_lfit,limit_1,h_1080", "about": "https://tse2-mm.cn.bing.net/th/id/OIP-C.x34pnUHj7vm9hpNc0uQrqQAAAA?rs=1&pid=ImgDetMain" }

  • default: 表示如果页面没有配置背景图片, 那么就是用该图片作为背景

  • home: 表示配置主页背景图片为该图片, 不使用default指定的图片作为背景

  • about: 表示配置关于页面背景图片为该图片, 不适用默认default指定的图片作为背景

Tips: 其他没有配置背景图片的页面会显示 default 指定的图片, 如果json格式错误, 那么配置会失败. 如果指定的图片不存在背景图片则不显示.

使配置生效

在主页中点击主题切换按钮切换一下主题即可让配置生效
