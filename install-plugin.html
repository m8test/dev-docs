安装插件

安装插件的方法有很多种, 例如本地安装、网络安装以及插件市场安装。

从本地安装

如果你已经把插件下载到本地, 例如在手机 /sdcard/Download 目录下, 那么可以通过以下两种方式安装

通过文件浏览器安装(推荐)

在app主页，点击存储

点击自定义

输入 /sdcard 后点击确定, 这里必须要有管理外部存储的权限, 否则看不到文件

找到下载好的插件后点击

选择安装插件

点击安装即可, 这种方式可以安装任何类型的插件

在插件列表页面安装

这种安装方式只能安装特定类型的插件, 例如通用插件列表页面只能安装通用插件, 语言插件列表界面只能安装语言插件。

这里演示如何安装通用插件，其他类型插件也是类似的操作, 在 app 主页点击插件

点击通用

点击右上角的添加按钮

点击更改

点击更改路径

输入 /sdcard 然后点击确定

选择插件所在的本地路径后点击确定

可以看到插件的详细信息,点击添加即可

从网络安装

通过文件浏览器安装(推荐)

在app主页，点击存储

点击自定义

输入 /sdcard 后点击确定, 这里必须要有管理外部存储的权限, 否则看不到文件

然后随便找一个目录, 这里我选择 /sdcard/Download, 然后点击右上角的菜单按钮

点击下载文件

输入下载地址以及下载到本地的文件名后点击确定

文件下载好后点击文件

选择安装插件

点击安装即可, 这种方式可以安装任何类型的插件

在插件列表页面安装

这种安装方式只能安装特定类型的插件, 例如通用插件列表页面只能安装通用插件, 语言插件列表界面只能安装语言插件。

这里演示如何安装通用插件，其他类型插件也是类似的操作, 在 app 主页点击插件

点击通用

点击右上角的添加按钮

点击网址

输入网址后点击下载

下载完成后点击添加即可

从插件市场安装(推荐)

在 app 主页点击插件

点击通用

保证已经安装了插件市场插件, 点击进入插件

可以看到插件市场中的插件

点击需要安装的插件

点击安装即可
