搭建 IDEA 开发环境

Tips: IntelliJ IDEA 支持 M8Test 所有语言，但使用 JavaScript 时可能会有些卡顿，具体原因未知。若主要开发 JavaScript，建议改用 VSCode，体验会更流畅。

M8Test脚本项目使用 Gradle 作为构建系统，提供强大的一站式开发体验。无需安装额外调试插件，只需在手机端开启 ADB 调试功能，即可通过数据线或 Wi-Fi 连接 安卓设备进行开发测试。

安装 IntelliJ IDEA Ultimate

如果您已安装 IntelliJ IDEA Ultimate ，可跳过此步骤，但建议idea版本始终保持最新版。

  1. 在 qq群文件 中下载 IntelliJ IDEA Ultimate 压缩包以及 M8Test 插件压缩包。

  2. 解压 IntelliJ IDEA Ultimate 压缩包到任意目录(ideaIU-2025.1.2.win.zip)

  3. 进入解压目录，找到 m8test 子目录，双击运行 start_idea.bat 文件启动 IDEA。首次启动需通过此脚本初始化环境，后续可直接通过 IDEA 安装目录下的 bin\idea64.exe 启动，也可创建桌面快捷方式方便使用。

  4. 若系统弹出 Windows 已保护你的电脑 安全提示，请按以下步骤操作：

    • 点击「更多信息」

    • 点击「仍要运行」继续执行

  5. IDEA 启动后，在激活界面选择：

    • 点击 Activate License

    • 选择 Activation Code 激活方式，输入从 QQ 频道 m8testofficial 获取的激活码，然后点击 Activate

  6. 激活成功后，在导入设置界面点击 Skip Import 跳过设置导入

  1. 打开 JetBrains 官网，下载适用于Linux系统的IDEA安装包至本地

  1. 在命令行中执行以下命令，将下载的安装包解压并移动至/opt目录：

tar -zxvf ~/Downloads/ideaIU-*.tar.gz -C /opt

  1. 下载破解包 ，并使用以下命令解压到指定目录：

unzip ~/Downloads/ja-netfilter.zip -d /opt/idea-IU-252.25557.131/ja-netfilter

  1. 编辑/opt/idea-IU-252.25557.131/bin/idea64.vmoptions文件：

vim /opt/idea-IU-252.25557.131/bin/idea64.vmoptions

在文件末尾添加以下内容：

-javaagent:/opt/idea-IU-252.25557.131/ja-netfilter/ja-netfilter.jar=jetbrains --add-opens=java.base/jdk.internal.org.objectweb.asm=ALL-UNNAMED --add-opens=java.base/jdk.internal.org.objectweb.asm.tree=ALL-UNNAMED

  1. 打开 QQ频道 ，复制激活码至剪贴板

  1. 启动IDEA，执行命令：

/opt/idea-IU-252.25557.131/bin/idea

启动后依次点击 plugins > installed > 任意一个ultimate插件 > Activate subscription

  1. 激活成功后，可看到如下激活信息

安装语言插件

一、无需安装插件的语言

若您使用以下语言开发脚本，无需安装任何额外插件：

  • Groovy

  • Java

  • JavaScript

  • Kotlin

二、需要安装插件的语言

若您使用的是上述语言以外的其他语言，则需安装对应的语言插件。

三、安装注意事项

  1. 请确保从官方插件市场下载，以保证安全性和兼容性

  2. 安装完成后，可能需要重启idea以使插件生效

  3. 若遇到插件版本不兼容问题，请查阅官方文档或社区支持

安装 M8Test 插件

M8Test 插件不是必须安装的，如果你不需要使用 M8Test 插件功能 ，可跳过此步骤, 最新版插件可以在 Github 下载。

  1. 在 IDEA 主界面，依次点击：

    • File > Settings > Plugins

    • 在已安装的插件列表中, 查找 M8Test 插件, 查看其当前版本。例如, 若已成功安装，版本可能显示为 0.1.1 。不过，也存在 M8Test 插件未安装的可能性 。

  2. 若当前版本不是最新版 ，点击插件列表右上角设置图标，选择 Install Plugin from Disk

  3. 在文件选择对话框中，定位并选择之前下载的 M8Test 插件压缩包，点击 打开

  4. 若弹出 Third-Party Plugins Notice 提示框，点击 Accept 确认安装第三方插件

  5. 插件更新完成后，点击 Restart IDE 重启 IDEA 使更改生效

  6. 在确认对话框中点击 Restart 立即重启

安装 M8Test 环境

如果您的网络能够访问外网，可直接下载并打开一个 M8Test gradle 脚本项目, 运行项目的时候会自动下载所需要的文件, 不需要手动安装 M8Test 环境, 也就是可以直接跳过此步骤, 更多内容请参考 M8Test开发环境。

  1. IDE 重启完成后，创建新项目：

    • 点击 File > New > Project

  2. 在项目模板列表中选择 M8Test ，任选一种开发语言，点击 Next 。由于尚未安装 M8Test 环境，此时创建的项目将为空项目

  3. 输入项目名称，选择保存路径，点击 Create （本文示例使用默认值）

  4. 项目创建完成后，按下快捷键 Alt-T 打开工具菜单，找到 M8Test 选项，点击 安装环境

  5. 在弹出的路径配置对话框中，输入 M8Test 开发环境压缩包的完整路径（可以在 github 下载），点击 Ok 开始安装

  6. 等待安装过程完成，期间请勿中断操作

  7. 安装完成后，点击 Ok 确认

创建项目

如果您的网络能够访问外网，可直接下载并打开一个 M8Test gradle 脚本项目, 无需通过 UI 创建项目, 也就是可以直接跳过此步骤。

  1. 使用快捷键 Alt-F 打开文件菜单，依次选择 New > Project

  2. 在项目模板列表中选择 M8Test ，根据需求选择具体的编程语言项目类型，点击 Next

  3. 设置项目名称和保存路径，点击 Create

  4. 在项目打开方式对话框中，选择 This Window 在当前窗口打开项目

配置 Gradle JDK

  1. 项目打开后，IDEA 会自动识别为 Gradle 项目，此时点击弹出通知中的 Load Gradle Project 按钮加载项目

  2. 若系统弹出 Download JDK 对话框，点击 Cancel 取消。因为 IDEA 已自带 JDK，我们只需配置其路径即可

  3. 点击 Open Gradle Settings 打开 Gradle 配置界面, 或者通过 Ctrl-Alt-S 打开设置依次选择 Build, Execution, Deployment > Build Tools > Gradle

  4. 找到 Gradle JVM 选项，点击右侧输入框后选择 Add JDK from Disk

  5. 在弹出对话框的文件浏览器中，选择 IDEA 解压目录下的 jbr 目录，点击 选择文件夹 完成 JDK 添加

  6. 确认 JDK 添加成功后，点击 Apply 应用设置，再点击 Ok 关闭配置窗口

  7. 点击 Gradle 工具窗口中的刷新按钮，同步项目依赖

后续操作

完成上述步骤后，可继续查看 使用Gradle项目模板 了解如何配置/运行/打包项目。
