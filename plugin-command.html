插件命令

M8Test 支持通过命令管理插件, 如果还不知道如何使用命令, 可以参考 命令 章节

安装插件

plugin install --path /path/to/plugin --url https://www.xxx.com/yyy.apk

  • plugin install: 表示安装插件

  • --path /path/to/plugin: 指定插件所在的本地路径

  • --url https://www.xxx.com/yyy.ak: 如果--path指定的本地文件不存在的话那么会通过此地址下载并保存到--path指定的路径后再安装

plugin install --path /sdcard/M8Test/language/groovy-0.1.0.apk --url https://github.com/m8test/language-release/releases/download/groovy-0.1.0/com.m8test.groovy-release_0.1.0.apk

卸载插件

plugin uninstall --name xxx --version yyy --type zzz

  • plugin uninstall: 表示卸载插件

  • --name xxx: 指定需要卸载的插件名

  • --version yyy: 指定需要卸载的插件版本

  • --type zzz: 指定需要卸载插件的类型, 例如语言插件为 language, 通用插件为 common 等

plugin uninstall --name Groovy --version 0.1.0 --type language
