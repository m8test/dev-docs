安装语言插件

默认情况下，App 自带 Java 语言支持。您可以通过安装语言插件来扩展更多编程语言的支持。

快速入门仅演示在手机端开发的最简流程，步骤会稍多。若进行正式项目开发，推荐改为在电脑端开发 ：无需事先在手机上安装 App，电脑端一键操作即可自动完成安装；手机端仅需手动授予权限即可。

语言插件可在 GitHub 手动下载；若用电脑开发，插件会自动安装到安卓设备，无需额外操作。

在主页面中点击“插件”。

选择“语言”。

点击右上角的添加按钮。

点击 “更改” 按钮。

点击 "更改路径" 按钮

在输入框中输入 /sdcard ，然后点击“确定”，应用便会列出 SD 卡中的所有文件（前提是已授予其管理外部存储的权限）。

选择你下载的语言插件，然后点击"确定"按钮

选择本地语言插件路径后，点击“添加”按钮。

添加完成后，即可看到对应的编程语言。如需支持更多编程语言，可重复上述操作！

现在，您已经可以开始编写该语言的脚本啦。
