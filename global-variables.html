全局变量

TIPS: 只有在脚本入口文件或初始化脚本文件中才能使用全局变量。通过入口文件引用的其他脚本文件无法直接使用全局变量，需要将其作为参数传递到这些脚本文件中。

全局变量是在编写脚本时可直接使用的变量。全局变量分为系统全局变量和第三方全局变量 ，为便于区分全局变量与普通变量，全局变量通常会添加前缀，不同编程语言使用的前缀可能有所不同,

  • 第三方全局变量由组件提供，只有在脚本运行时引入相应组件，才能使用该组件中的全局变量。

  • 系统全局变量由M8Test提供，默认包含:

    • Activity

    • Arrays

    • Branches

    • BuildScriptConfig

    • Console

    • DateTimes

    • Events

    • Exceptions

    • Files

    • Iterables

    • Loops

    • Maps

    • Project

    • Reflectors

    • Script

    • ScriptEngine

    • Sequences

    • Settings

    • Threads

    • WebResources

    • WebView

下面这个例子中引入了所有全局变量，并使用全局变量($console/_console)输出内容到控制台。

// 导入所有全局变量 import com.m8test.script.GlobalVariables.*; // 输出内容到控制台 _console.log("Hello World");
// 输出内容到控制台 $console.log("Hello World");
// 导入所有全局变量 import static com.m8test.script.GlobalVariables.*; // 输出内容到控制台 $console.log("Hello World");
// 输出内容到控制台 $console.log("Hello World");
-- 输出内容到控制台 _console:log("Hello World")
<?php // 下面的文档注释是为了有代码提示功能 /** @var m8test_java\com\m8test\script\core\api\console\Console $console */ global $console; // 输出内容到控制台 $console->log("Hello World");
# 导入全局变量 from m8test_java.com.m8test.script.GlobalVariables import _console # 输出内容到控制台 _console.log("Hello World")
# 输出内容到控制台 $console.log("Hello World")
