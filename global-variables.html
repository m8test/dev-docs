全局变量

全局变量是在编写脚本时可以直接在脚本中使用的变量, 全局变量分为系统全局变量和第三方全局变量，全局变量有:

  • Activity

  • Arrays

  • Branches

  • BuildScriptConfig

  • Console

  • DateTimes

  • Events

  • Exceptions

  • Files

  • Iterables

  • Loops

  • Maps

  • Project

  • Reflectors

  • Script

  • ScriptEngine

  • Sequences

  • Settings

  • Threads

  • WebResources

  • WebView

第三方全局变量由组件提供, 只有在脚本运行时引入某个组件才可以使用组件中的全局变量。为了区分全局变量和一般变量，全局变量一般取添加前缀，不同变成语言添加的前缀可能不一样。
