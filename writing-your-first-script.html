编写第一个脚本

快速入门仅演示在手机端开发的最简流程，步骤会稍多。若进行正式项目开发，推荐改为在电脑端开发 ：无需事先在手机上安装 App，电脑端一键操作即可自动完成安装；手机端仅需手动授予权限即可。

打开 App，点击 脚本。

点击右上角的菜单按钮。

点击 新建文件。

输入文件名后点击 确定。

点击新创建的文件。

选择编辑器打开该文件。

输入下面代码 ，然后按照下图顺序点击按钮保存内容并返回。

// 导入所有全局变量 import static com.m8test.script.GlobalVariables.*; // 输出内容到控制台 $console.log("Hello World");

点击运行按钮。

点击运行。

至此，第一个脚本已成功编写并运行, 我们可以在日志界面中看到脚本输出的内容。
